# LeadSphere Premium Portfolio

Create a stunning, premium, modern portfolio website for a company/product called “LeadSphere”.

LeadSphere is a modern lead generation, lead management, and business growth platform that helps businesses capture, organize, qualify, and convert leads efficiently.

The website should feel like a premium SaaS/startup brand — visually impressive, trustworthy, sophisticated, and conversion-focused.

IMPORTANT DESIGN DIRECTION:

- Modern premium SaaS aesthetic

- Clean but visually rich

- Strong typography

- Lots of breathing space

- Subtle gradients

- Glassmorphism used carefully

- Soft shadows

- Rounded cards and buttons

- Smooth micro-interactions

- High-end startup feel similar to Stripe, Linear, Framer, Vercel and modern AI SaaS websites

- Avoid generic templates

- Avoid excessive gradients

- Avoid clutter

- Every section should have a clear visual hierarchy

- Fully responsive for desktop, tablet and mobile

BRAND:

Name: LeadSphere

Tagline:

“Turn Every Lead Into an Opportunity.”

Suggested supporting text:

“LeadSphere helps modern businesses capture, organize, qualify and convert leads with smarter workflows and powerful insights.”

COLOR SYSTEM:

Primary: Deep navy / near-black

Secondary: Electric blue

Accent: Violet / purple

Background: #F8FAFC for light sections

Dark sections: #080B14

Text: #0B1220

Muted text: #64748B

White: #FFFFFF

Use gradients sparingly:

Blue → Violet

Indigo → Electric Blue

TYPOGRAPHY:

Use a modern font such as Inter, Manrope, Plus Jakarta Sans or Geist.

Headings should be bold, large and highly readable.

Use strong typography hierarchy.

ANIMATIONS

--------------------------------------------------

Use animations throughout the site but keep them premium and subtle.

Page load:

- Logo fades in

- Hero headline slides upward

- Supporting text fades in

- CTA buttons appear

- 3D sphere slowly enters

Scroll:

- Sections reveal using fade + translateY

- Cards stagger into view

- Statistics count up

- Dashboard charts animate

- Process timeline activates progressively

Buttons:

Every button should have micro-interactions.

Primary button hover:

- Slight upward movement

- Soft glow

- Arrow moves right

Secondary button hover:

- Background appears

- Border becomes brighter

Cards:

- translateY(-6px)

- subtle scale 1.01

- soft shadow

- border glow

Do not overuse animations.

Use Framer Motion / GSAP if available.

--------------------------------------------------

INTERACTION DETAILS

--------------------------------------------------

Buttons should feel tactile.

Use:

- hover

- active

- focus

- subtle magnetic effect for major CTA buttons

- animated arrow icons

Links should have smooth underline animations.

Cards should respond to mouse movement with subtle 3D tilt where appropriate.

Use smooth scrolling between sections.

RESPONSIVE DESIGN

--------------------------------------------------

Desktop:

Premium wide layout with generous whitespace.

Tablet:

Adapt grids from 3 columns to 2 columns.

Mobile:

Single-column layout.

Hero becomes stacked.

3D sphere moves below CTA.

Hide complex decorative elements if they affect performance.

Keep all animations lightweight.

Mobile buttons should be full-width or comfortably sized.
